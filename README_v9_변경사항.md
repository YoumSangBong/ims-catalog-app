# v9 업데이트 — "1. 기준정보 조회" 화면에 수정 기능 추가

이번 업데이트는 스키마 변경이 없습니다(마이그레이션 스크립트 실행 불필요) — `app.py`만
교체하면 됩니다.

## 추가된 내용
1. **sample_original(Original 현황)**: 지금까지는 조회만 가능했는데, 이름을 잘못
   등록했거나 새로 추가하고 싶을 때 화면에서 바로 수정·추가할 수 있게 되었습니다.
   (삭제는 지원하지 않습니다 — 이미 신청건에서 참조 중일 수 있어서, 잘못된 경우
   이름을 올바르게 고쳐서 재사용하는 방식을 권장합니다.)
2. **form_pattern(양식 패턴)**: 마찬가지로 조회만 가능했던 화면에 pattern_code/
   pattern_name/description 추가·수정 기능을 넣었습니다. pattern_code는 doc_type에서
   참조하므로 신규 추가 시에만 입력 가능하고, 기존 항목은 이름/설명만 고칠 수 있습니다
   (삭제 미지원, 사유는 위와 동일).

(참고: v8에서 이미 "standard(규격)"와 "doc_type" 화면에는 비슷한 방식의 추가·수정
기능이 들어가 있습니다 — 이번 v9는 나머지 두 화면에 같은 패턴을 적용한 것입니다.)
