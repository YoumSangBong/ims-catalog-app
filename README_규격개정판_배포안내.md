## 배포 순서
1. `scripts/11_migrate_standard_editions.py`를 먼저 실행하세요 (기존 10번 마이그레이션이 이미
   적용된 DB를 전제로 합니다). 멱등성이 있어 재실행해도 안전합니다.

   ```
   cd scripts
   python 11_migrate_standard_editions.py
   ```

2. `app.py`를 교체하세요.

## 이번 업데이트 반영 내용 (2026-09-18 협의 확정)
1. `standard` 테이블에 개정판 지원 컬럼 추가 — edition_label, valid_from/valid_until(유효기간),
   is_current_default, sort_order(조합 코드 생성 순서), is_active(소프트 비활성화).
   기존 q/e/hs 3종은 그대로 유지되고, 2026년판처럼 새 개정판은 **대문자**(Q, E)로 등록합니다
   (hs/ISO45001은 개정판이 없으므로 HS는 없음). "1. 기준정보 조회 → standard" 화면에서
   추가·수정·소프트비활성화가 가능합니다.
2. 사용자 등록 화면의 규격 선택이 기존 7개 고정 콤보 대신, standard 테이블 기반 다중선택으로
   바뀌었습니다. 유효기간이 지난 규격은 신규 등록 목록에서 자동으로 빠집니다.
3. **규격 개정은 기존 프로젝트 수정이 아니라 새 프로젝트 등록**으로 처리합니다 — "수정" 모드에서는
   규격 선택이 잠깁니다(변경 불가). 개정판으로 넘어가려면 "복사해서 새로 등록"을 쓰고, 원본을
   대체하는 경우 체크박스를 켜면 `application.superseded_application_id`로 이력이 연결됩니다.
   "2. 사용자 관리 → 사용자 목록"에 대체 이력 컬럼과, 유효기한이 180일 이내인데 아직 후속
   프로젝트가 없는 항목에 대한 경고 목록이 추가되었습니다.
4. `doc_type.clause_ref_overrides` — 개정판마다 조항번호가 다르거나(예: ISO 9001:2026 신설
   6.1.3) 조항 자체가 없어진 경우(예: ISO 14001:2026의 6.1.1 소멸)를 문서종류별로 등록하는
   화면을 "1. 기준정보 조회 → doc_type" 하단에 추가했습니다.
